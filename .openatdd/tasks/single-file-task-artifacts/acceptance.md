# 验收卡：single-file-task-artifacts

## 目标

将 OpenATDD 重构为每个需求在工作区只产生一个渐进式披露的 Markdown 文件，机器状态集中存储在 Git 私有运行目录，人工验收入口与完整操作链路置于交付文件第一屏

## 建议用户旅程

1. 待填写：描述真实用户的第一个动作。
2. 待填写：描述可观察的成功结果。

## 验收标准

### AC-01 [AUTO] [BLOCKING] 待填写：命名一个可观察结果
- 前提：待填写
- 操作：待填写
- 结果：待填写
- 证据：待填写

## 边界

- 待填写：说明重要范围、角色、环境或排除项。
